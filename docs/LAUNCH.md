# Launch playbook (condensed from the AFFiNE 0→60k case study)

## Before you post anything
- [ ] `bash demo.sh` green on a fresh clone (60 seconds, no install).
- [ ] README answers in 7 seconds: problem → GIF/transcript → install → 3 uses.
- [ ] 100–200 seeded stars from your network FIRST (a 0-star README converts ~nobody).
- [ ] Pick Tue–Thu, ~9am PT. One 48-hour window for everything below.

## The 48-hour window (order matters)
1. Hour 0–6: Reddit — r/selfhosted, r/opensource, niche (r/Python, r/javascript). Lead with the pain, not the project. No "please star".
2. Hour 6–12: Show HN — "Show HN: I got paged by flaky tests, so I built …" + live demo + honest benchmarks. Stay in the comments all day.
3. Hour 12–24: Product Hunt (badge = README social proof).
4. Hour 24–48: X/thread with numbers, Dev.to cross-post, 5–10 newsletter pitches citing Trending placement.

## Why this order
GitHub Trending ranks **velocity**, not totals (~30–60 stars/day for language trending). Four small spikes across a week each miss it; one combined spike crosses it — then Trending markets for you.

## After the spike (compounding)
- Reply to EVERY comment/issue within 12h for the first week (alive-project signal).
- Weekly cadence: one post/release — real-repo benchmark study, new FLK rule with data, `npx` wrapper, framework emitter.
- Submit to awesome lists (awesome-python, awesome-javascript, awesome-claude-code…): 50–200 stars/month on autopilot each.
- After 1k stars: 1v1 user calls; after 6k: listen more than broadcast.
